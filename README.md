## What's Inside

A single-file SPA (`index.html`) built with [Tailwind CSS CDN](https://tailwindcss.com), [Phosphor Icons](https://phosphoricons.com), and vanilla JavaScript. No build step required — push and it just works.

## Deploying to GitHub Pages

1. Create a public GitHub repository (e.g. `sankush.github.io`).
2. Add `index.html` and `sankush-128x128.png` (your logo) to the root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` / `(root)`, and save.
5. Your site will be live at `https://<your-username>.github.io` within a minute.
