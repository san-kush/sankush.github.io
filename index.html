This website is engineered as a 100% static, zero-dependency single-page application (index.html) so you can host it for free forever on GitHub Pages:

  1. Create a new public repository on GitHub (e.g., sankush-technologies).
  2. Upload this index.html file and your logo file sankush-128x128.png to the root of the repository.
  3. Open your repository Settings → Pages in the left sidebar.
  4. Under Build and deployment (Source), select Deploy from a branch, choose main and / (root), and click Save.
  5. Within 60 seconds, your live Sankush Technologies site will be published at https://<your-username>.github.io/sankush-technologies/!
